# 🇹🇷 Мозаика Республики · Ататюрк

Интерактивная рефлексия для урока истории «Мустафа Кемаль Ататюрк — основатель Турецкой Республики».

**Идея:** студенты сканируют QR-код и отправляют имя и короткий ответ о том, что запомнилось об Ататюрке. Каждое сообщение открывает **6 элементов мозаики**. После 25 ответов мозаика полностью открывает изображение турецкого флага. При нажатии на раскрытый фрагмент преподаватель видит автора и ответ. Сайт обновляется каждые 3 секунды.

## Страницы

- `https://ВАШ-САЙТ.streamlit.app/` — мозаика с QR-кодом, для проектора.
- `https://ВАШ-САЙТ.streamlit.app/?view=student` — форма студента.
- `https://ВАШ-САЙТ.streamlit.app/?view=admin` — управление преподавателя по паролю.

## Размещение на Streamlit Community Cloud

1. Создайте **новый** публичный репозиторий GitHub, например `ataturk-republic-mosaic`.
2. Загрузите **содержимое** этого архива. Файлы `app.py` и `requirements.txt` должны находиться в **корне** репозитория. Старый `shanyraq-oi-qos` менять не нужно.
3. Перейдите на https://share.streamlit.io → **Create app** → выберите новый репозиторий, ветку `main`, главный файл `app.py` → **Deploy**.
4. В Streamlit Cloud откройте настройки приложения → **Secrets** и добавьте **свой** пароль:

```toml
ADMIN_PASSWORD = "свой-сложный-пароль"
```

5. Откройте URL приложения на проекторе; студенты сканируют QR-код и отправляют ответы с телефонов. Для проверки отправьте тестовый ответ с телефона.

## Возможности преподавателя

- Отдельная панель с паролем
- Удаление выбранного ответа
- Полная очистка мозаики с подтверждением
- Скачивание ответов (CSV с BOM для Excel)

**Важно:** ответы хранятся в SQLite на сервере Streamlit Community Cloud. База **не гарантирует сохранение после перезапуска, сна или переразвёртывания приложения**. Для одного занятия это удобно, но для постоянного хранения нужна внешняя база. Перед перезапуском скачивайте CSV через панель преподавателя.

Также обратите внимание, что если число участников превышает 25, флаг уже будет открыт полностью, но остальные отзывы продолжат появляться в списке и в CSV. Отправленные имена и ответы публично показываются на проекторе.
